Synopsis

Parse PostgreSQL DDL and DML: Haskell bindings for libpg_query

Description

pg-query offers Haskell bindings for @<https://github.com/pganalyze/libpg_query libpg_query>@, which makes use of the actual PostgreSQL server source to parse SQL queries and return the internal PostgreSQL parse tree.
